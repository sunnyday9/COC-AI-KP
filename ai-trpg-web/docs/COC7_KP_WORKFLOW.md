# COC 7th Edition - AI KP Agent 标准工作流分析

> 基于《克苏鲁的呼唤 第七版 守秘人规则书》分析，用于指导 AI KP Agent 的 LangGraph 工作流设计。

---

## 一、KP 核心循环（每回合）

```
玩家输入 → 意图识别 → 是否需要检定？ → 执行检定/工具 → 叙事回应 → 推进剧情
```

### 1.1 标准回合流程

1. **接收玩家行动描述**（玩家说出想做什么）
2. **KP 判断该行动是否需要骰子检定**
   - 日常/常规行动 → 无需检定，直接叙述结果
   - 有戏剧性冲突/不确定性 → 需要检定
3. **确定检定参数**（技能、难度等级）
4. **执行骰子投掷**（d100 技能检定 或 其他骰子）
5. **判读结果**（成功/失败/大成功/大失败）
6. **叙述结果并推进剧情**
7. **应用副作用**（HP/SAN/MP 变化、场景切换、线索发现等）

## 二、技能检定工作流

### 2.1 何时需要检定

| 情况 | 是否需要检定 |
|------|-------------|
| 行动是角色职业的日常操作 | ❌ 自动成功 |
| 没有戏剧性冲突或时间压力 | ❌ 自动成功 |
| NPC 倾向于配合玩家请求 | ❌ 自动成功 |
| 存在冲突、对抗或危险 | ✅ 需要检定 |
| 结果不确定且对故事有影响 | ✅ 需要检定 |
| 有时间压力或生命危险 | ✅ 需要检定 |

### 2.2 难度等级

| 难度 | 阈值 | 使用条件 |
|------|------|----------|
| 常规（Regular） | ≤ 技能值 | 默认难度，对手技能 < 50 |
| 困难（Hard） | ≤ 技能值/2 | 对手技能 ≥ 50，或显著困难的非对抗障碍 |
| 极难（Extreme） | ≤ 技能值/5 | 对手技能 ≥ 90，或人类能力极限 |

### 2.3 检定结果判读

| d100 结果 | 判定 | 说明 |
|-----------|------|------|
| 01 | 大成功 | 额外奖励，KP 决定具体内容 |
| ≤ 阈值 | 成功 | 玩家达成目标 |
| > 阈值 | 失败 | KP 叙述后果（失败 ≠ 灾难） |
| 96-100（技能<50）或 100（技能≥50） | 大失败 | 灾难性后果立即发生 |

### 2.4 孤注一掷（Pushing Rolls）

当技能检定失败时，玩家可以选择"孤注一掷"：

1. 玩家描述如何付出额外努力/冒险
2. KP 可预示失败后果（"如果失败了……"）
3. 重新投骰，使用相同技能和难度
4. **成功**：达成目标
5. **失败**：KP 可施加严重后果 — 受伤、SAN 损失、装备损坏、被俘、分离

**不可孤注一掷的检定**：幸运检定、SAN 检定、战斗检定、伤害骰

### 2.5 奖励骰/惩罚骰

- 每个奖励骰：额外投一颗十位骰，取更优（更低）结果
- 每个惩罚骰：额外投一颗十位骰，取更差（更高）结果
- 一个奖励骰抵消一个惩罚骰
- 仅在情境显著有利/不利时使用

## 三、理智检定（SAN Check）工作流

### 3.1 触发条件

- 遭遇克苏鲁神话生物/实体
- 目睹恐怖场景（尸体、暴力、超自然事件）
- 阅读神话典籍（完成学习后）
- KP 判断情境需要时

### 3.2 检定流程

1. 玩家 d100 对当前 SAN 值
2. **成功** → 损失斜杠前的数值（通常 0 或 1）
3. **失败** → 损失斜杠后的数值（如 1d6）
4. **大失败(100)** → 损失最大可能 SAN
5. SAN 检定不使用奖励骰/惩罚骰
6. 失败时，KP 描述一个不由自主的反应（尖叫、掉落物品、呆立、暴力反应）

### 3.3 疯狂触发

| 条件 | 结果 |
|------|------|
| 一次损失 5+ SAN | INT 检定 → 成功=临时疯狂 |
| 一"天"内损失 ≥ 当前SAN的1/5 | 不定性疯狂 |
| SAN 降至 0 | 永久性疯狂（角色退役） |

### 3.4 疯狂发作

- 控制权转移到 KP
- 发作期间不再损失 SAN
- **有同伴在场**：持续 1d10 战斗轮，使用即时症状表
- **独自/全员疯狂**：持续 1d10 小时，KP 叙述结果
- 即时症状：失忆、心因性残疾、暴力、偏执、晕厥、逃跑、歇斯底里、恐惧症、躁狂等

## 四、战斗工作流

### 4.1 先攻顺序

1. 按 DEX 从高到低排列
2. 已准备好的枪械：DEX + 50
3. 平局由战斗技能较高者先行
4. 每角色每轮一次行动

### 4.2 近战解决

1. 攻击者声明行动
2. 防御者选择：**反击**或**闪避**或不反应
3. 双方进行对抗检定
4. 较高成功等级获胜：
   - **攻击者胜（反击）** → 命中并造成伤害
   - **防御者胜（反击）** → 格挡且反击造成伤害
   - **防御者胜（闪避）** → 双方无伤害
   - **双方失败** → 无伤害

### 4.3 射击

- 基础射程=常规难度，2x=困难，4x=极难
- 掩体、移动目标、瞄准等使用奖励骰/惩罚骰调整
- 目标不能反击枪械，只能闪避（给攻击者惩罚骰）

### 4.4 伤害计算

- 投掷武器伤害 + 伤害加值
- **极难成功（攻击者回合）**：最大伤害 + 贯穿武器额外伤害骰
- 减去目标护甲值

## 五、场景与叙事管理

### 5.1 场景推进原则

1. **描述场景** — 设定氛围、地点、在场 NPC
2. **询问玩家** — "你打算怎么做？"
3. **判断是否需要检定** — 只对有戏剧性/对抗性的情况
4. **设定难度并确定技能** — 告知玩家需要投掷什么
5. **解读结果** — 成功=玩家叙述；失败=KP 叙述
6. **推进叙事** — 后果自然流入下一个节拍

### 5.2 节奏控制

- 交替进行紧张行动和安静调查
- 调查员分散时：管理不同"场景"并在悬念处切换
- 允许玩家讨论策略，但在停滞时介入
- 结构：开场 → 紧张上升 → 高潮 → 结局

### 5.3 线索传递系统

| 线索类型 | 是否需要检定 | 目的 |
|----------|-------------|------|
| 显明线索 | 不需要检定 | 推动剧情关键线索，必须给予 |
| 隐秘线索 | 需要感知检定 | 有帮助但非必须，增加紧张感 |

**关键原则**：
- **绝不**让单一隐秘线索成为唯一的推进路径
- 提供多种方式发现关键信息
- 感知失败时：玩家知道错过了某些东西（元紧张感）

### 5.4 灵感检定（调查员卡住时）

- 最高 INT 的调查员投骰
- 成功：KP 自然地将线索编入叙事
- 失败：KP 仍给出线索，但将调查员置于直接危险中

## 六、KP 决策框架

### 6.1 六条投骰规则

1. **KP 决定何时**需要检定（跳过琐碎/常规事项）
2. **结果是叙事工具**，不是绝对定论
3. **失败 ≠ 完全失败** — 可能是部分成功、挫折或情况改变
4. **成功=玩家叙述；失败=KP叙述**（共同讲故事）
5. **避免连续相同检定** — 一次检定覆盖整个序列；改为提升难度
6. **考虑大局** — 每次投骰都应服务于故事

### 6.2 致命遭遇前的三次警告

1. 规划讨论中的对话暗示
2. 场景中的 NPC 警告或环境线索
3. 直接的感官警告（声音、气味、视觉危险信号）

### 6.3 信息传递原则

- 描述证据，而非结论
- "地毯上有泥泞的脚印" 而非 "有人从窗户闯入"
- "那个生物没有生命迹象" 而非 "它死了"
- "你没有发现任何东西" 而非 "这里什么都没有"
- 留有疑虑和不确定性 — 这正是恐怖的来源

### 6.4 恐怖升级

- 孤注一掷失败 = 升级恐怖
- 层叠问题（邪教 → 时限 → 背叛 → 黑暗交易）
- 对处于潜在疯狂状态的调查员使用幻觉
- 通过疯狂腐蚀背景故事条目
- "少即是多" 描述神话生物 — 暗示而非完全揭示
- 使用全部感官（嗅觉、听觉、触觉）而非仅视觉

## 七、AI KP Agent 工具映射

基于以上工作流，AI KP Agent 需要以下工具：

| 工具 | 功能 | 触发时机 |
|------|------|----------|
| `skill_check` | 技能检定（d100 对角色技能值） | 玩家尝试需要检定的行动 |
| `roll_dice` | 通用骰子投掷（d6 伤害等） | 伤害计算、随机事件 |
| `san_check` | 理智检定（d100 对当前 SAN） | 遭遇恐怖/神话事物 |
| `adjust_hp` | 调整 HP | 受伤/治疗 |
| `adjust_san` | 调整 SAN | SAN 检定后损失/恢复 |
| `adjust_mp` | 调整 MP | 施法/恢复 |
| `transition_scene` | 场景切换 | 玩家移动到剧本中的合法场景 |
| `grant_clue` | 授予线索 | 调查成功或显明线索 |

### 7.1 推荐的 Agent 图结构

```
START
  → classifyIntent（意图分类）
  → assessAction（行动评估：是否需要检定，确定难度）
  → kpRespond（KP 回应：执行工具调用 + 叙事输出）
END
```

### 7.2 意图分类补充

在 COC 7th 规则下，意图应更精确地映射到 KP 决策：

| 意图 | KP 行为 |
|------|---------|
| `investigate` | 判断是否需要侦查/图书馆使用等检定，成功则给线索 |
| `skill_check` | 立即执行 skill_check 工具，根据结果叙述 |
| `talk_npc` | 判断是否需要社交技能检定（话术/说服/恐吓/魅惑） |
| `move` | 检查目标场景是否在剧本列表中，合法则 transition_scene |
| `combat` | 执行战斗流程：攻击检定 → 伤害 → adjust_hp |
| `explore` | 描述环境，可能触发线索发现或陷阱 |
| `use_item` | 判断物品使用效果，可能需要检定 |
| `wait/rest` | 时间推进，可能触发随机事件 |
| `narrative` | 一般叙事回应，推进氛围和剧情 |
